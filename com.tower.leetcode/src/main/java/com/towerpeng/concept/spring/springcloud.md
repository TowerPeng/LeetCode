微服务的优点：
1、可扩展性：允许单独扩展单个服务，不需要扩展整个应用程序，提供可扩展性
2、灵活和快速开发：微服务允许开发团队独立设计、开发和部署服务，提高了灵活性，允许团队更快的推出新功能。
3、故障隔离和容错性：单个微服务的故障通常不影响其他服务，提供了应用程序的容错性，同时更容易识别和解决故障。
4、技术多样性：微服务允许您选择合适每个服务的最佳技术栈，有助于充分利用各种技术和工具的优势。
5、独立部署和维护：微服务可以独立部署和维护，减少了风险，允许团队更轻松地管理应用程序。
6、团队协作：不同团队可以独立工作在不同服务上，提高了团队自治和协作能力，减少冲突。

网关作用：
1、统一入口：通过网关，所有请求都通过网关进入，从而实现统一入口，提高效率。
2、四大职责：
统一鉴权，token校验
动态路由，转发给对应的服务
限流熔断，利用限流算法，控制流量。
协议转换，转换协议。
