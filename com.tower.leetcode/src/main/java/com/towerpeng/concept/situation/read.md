在2G文件中，找出高频top100的单词
1、分块读取（内存控制）：可以按4MB为单位分块读取文件，使用BufferedReader逐行读取避免内存溢出，也可以动态调整分块大小（根据实际情况）
2、并行处理（性能优化）：使用线程池处理每个分块，每个线程独立统计局部词频，合并结果时使用ConcurrentHashMap保证线程安全。
3、全局合并（高效聚合）：使用Map.merge方法进行原子累加，同步代码块保证并发安全
4、TopK筛选（堆排序优化）：维护大小为100的最小堆，最终排序输出结果。具体过程就是如果遍历到的词的出现次数大于堆顶上词的出现次数，那么可以用心遍历到的词替换堆顶的词，然后重新调整这个堆为小顶堆。
当遍历完所有文件后，这个小顶堆的词就是出现频率最高的词100词。

1GB文件，快速判断某个无符号整数是否在40亿数据中
1、分块读取文件
使用BufferedInputStream设置512M的缓冲区，
遍历当前内存块中的所有整数
优点：无需预处理，零额外内存占用，实现简单
缺点：单次查询时间较长，多次查询需要重复全量读取文件
2、使用位图（bitMap）
每个整数直接映射到512MB位图中的二进制位
232位=8232字节=536870912字节≈512MB
覆盖范围：说有32位整数，0<=x<=4294967296
优点：查询时间O(1)，零误判，内存固定512MB
缺点：仅支持32位整数，最大42.9亿，无法处理超范围数据
3、布隆过滤器
优点：支持任意数据类型，内存效率高
缺点：高误判率1GB内存下≈39%，无法删除元素
