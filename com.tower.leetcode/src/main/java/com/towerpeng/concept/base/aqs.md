AQS (AbstractQueuedSynchronizer) 是java并发包中的一个抽象同步框架，它是JUC包中多个组件的底层实现，如ReentrantLock（独占），CountDownLatch，Semaphore（共享）等。
核心作用是统一封装了线程等待，唤醒排队机制，底层通过volatile state变量加FIFO队列来实现线程的资源争抢，state表示资源的状态，比如独占锁0表示没有人，1表示已上锁，如果线程抢不到锁就会送到队列里排队，这个队列是CLH队列，用双向链表来实现，
节点里还记录了线程的信息，等待状态等。一个线程来获取锁资源的时候，会判断state是否等于0，如果是0则把state更新为1，表示占用锁，此时如果有多个线程来获取锁，会通过unSafe类park方法进行阻塞，
把阻塞线程按照先进先出的原则加到双向链表结构中，当获取锁资源的线程释放锁后，会从双向链表的头部唤醒下一个等待的线程去竞争锁。
