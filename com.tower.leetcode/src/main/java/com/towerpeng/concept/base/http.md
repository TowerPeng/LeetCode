Ngix是什么：
Nginx 是一款轻量级的高性能 HTTP 服务器、反向代理服务器 以及 IMAP/POP3/SMTP 代理服务器。它以其高并发、低内存消耗和丰富的功能集而闻名，常用于负载均衡、静态资源服务、API 网关等场景。
负载均衡算法：
轮询（Round Robin），默认算法。按顺序将请求依次分配给每个后端服务器，循环往复。
加权轮询（Weighted Round Robin），在轮询基础上为每个服务器设置权重（weight），权重越高，被分配到的请求比例越大。
IP Hash，根据客户端 IP 地址的哈希结果分配服务器，使得同一客户端的请求总是被发往同一台后端服务器。
最少连接 （Least Connections）将请求分配给当前活跃连接数最少的服务器。
随机（random）从所有可用的服务器中随机选择一个（可附带权重）。
一致性哈希（Consistent Hash）通过通过配置 hash $request_uri consistent; 实现，根据指定变量（如 URI）的哈希值分配，且当服务器数量变化时，只有少量请求重新分配。
