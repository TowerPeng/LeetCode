反射（Reflection） 是程序在运行时能够自省、获取自身信息并动态操作对象的一种能力。在 Java 等静态语言中，反射允许程序在运行时：
获取任意类的完整结构（类名、父类、接口、构造器、方法、字段、注解等）
创建类的实例（即使类名在编译时未知）
调用对象的方法或访问/修改字段（包括私有的）
动态生成代理对象
反射是一种允许程序在运行时检查和操作类、接口、字段和方法的机制。通过反射，可以动态地获取类的信息、创建对象、调用方法、访问字段等。

Class.forName方法是一个静态方法，负责根据类名加载类，并执行静态初始化
ClassLoader是抽象类，提供了更灵活的类加载机制，可以自定义类加载过程，从不同源加载类文件。

Spring：IoC 容器通过反射创建 Bean、注入依赖；AOP 通过动态代理拦截方法。
MyBatis / Hibernate：根据实体类映射表结构，运行时生成 SQL 并填充结果集到对象。
Tomcat / Jetty：通过反射调用 Servlet 的 service 方法。
JUnit / TestNG：扫描带有 @Test 的方法并反射执行。

JDK 动态代理：基于接口的代理，通过 Proxy 和 InvocationHandler 在运行时生成代理类，拦截方法调用。Spring AOP 默认使用此方式。
CGLIB / ByteBuddy：通过字节码生成（底层也依赖反射）创建子类代理，用于没有接口的类。
